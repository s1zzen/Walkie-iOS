# Walkie iOS

iOS-клиент Walkie на SwiftUI с архитектурой MVVM и исследовательский стенд локального сопровождения прогулок. Срез реализации: 6 ноября 2026.

## Запуск

Откройте `apps/walkie_ios/Walkie.xcodeproj` в Xcode, выберите схему Walkie и симулятор iPhone. Для физического устройства выберите свою команду подписания. Настройка API и деморежима описана в `apps/walkie_ios/README.md`.

- `apps/walkie_ios/Walkie`: экраны, модели представления, API и локальное хранение.
- `apps/walkie_ios/Packages/WalkieCore`: алгоритмы, доменные модели и тесты.
- `apps/walkie_ios/RESEARCH.md`: исследовательский протокол.
- `experiments/walkie_field_lab`: отдельный стенд сбора и воспроизведения экспериментальных данных.

## Проверки

6 ноября: 132 теста приложения прошли; UI-сценарий истории прогулок с перезапуском прошёл. Это проверка реализации, а не результат полевого исследования.

Тесты: схема Walkie в Xcode; для ядра — `swift test` в `apps/walkie_ios/Packages/WalkieCore`.

## Ограничения

Шагомер проверяется на физическом iPhone. Доступность маршрутов зависит от API. В деморежиме предусмотрены локальные сценарии; TestFlight пока не опубликован. Личные GPS-треки, учётные данные и результаты сборок в репозиторий не включены.
